# Orba Android previews

Public APK downloads, checksums and release inventories for Orba. The application source is maintained separately.

Use the [Orba download page](https://orba-android-preview.baref00t.chatgpt.site/) for the current preview, installation steps, release notes and roadmap. APK build numbers and website versions are separate.

These are preview builds. Experimental capabilities and remaining validation are identified per release. A CPU/GPU selector does not establish a measured performance improvement or confirm observed hardware dispatch.

Third-party licence notices are bundled inside each APK; available release inventories and checksums accompany the assets. Keep existing app data by upgrading with the same package and signing certificate rather than uninstalling.
